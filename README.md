# Mavuno Website — primeira versão

Site institucional estático do Mavuno, desenvolvido com HTML, CSS e JavaScript puros.

## Executar
Abra `index.html` no navegador. Para desenvolvimento, pode usar a extensão Live Server do VS Code.

## Estrutura
- `index.html` — conteúdo e secções do site
- `css/style.css` — identidade visual e layout responsivo
- `js/script.js` — menu lateral e pequenas interações
- `assets/` — espaço para logótipo, imagens e ícones oficiais

## Antes de publicar
Substituir os textos provisórios e adicionar:
- URLs oficiais de download;
- preços e detalhes reais dos planos;
- contactos e canais oficiais de suporte;
- imagens e materiais definitivos do Mavuno.

O endereço `suporte@mavuno.example` é apenas ilustrativo e deve ser substituído ou removido.
