# Mavuno Website — primeira versão

Site institucional estático do Mavuno, desenvolvido com HTML, CSS e JavaScript puros.

## Executar
Abra `index.html` no navegador. Para desenvolvimento, pode usar a extensão Live Server do VS Code.

## Estrutura
- `index.html` — conteúdo e secções do site
- `download.html` — página independente para as opções oficiais de download
- `community.html` — página independente para a comunidade Mavuno
- `support.html` — página independente de Ajuda e suporte
- `css/style.css` — identidade visual e layout responsivo
- `js/script.js` — menu lateral e pequenas interações
- `assets/` — imagens e ícones oficiais do projeto
  - `astronaut.webp` — mascote usada dentro do logo flutuante do hero
  - `brand/astronaut-jump-original.png` — recurso original recebido para referência da mascote

## Antes de publicar
Substituir os textos provisórios e adicionar:
- URLs oficiais de download;
- preços e detalhes reais dos planos;
- contactos, WhatsApp Business e canais oficiais de suporte;
- imagens e materiais definitivos do Mavuno.

Os contactos e canais oficiais de suporte devem ser adicionados em `support.html` quando forem definidos.
